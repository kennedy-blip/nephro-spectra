# Android host project

The Gradle/Android project is generated by Capacitor in CI
(`.github/workflows/build-and-bundle-apk.yml` → `npx cap add android`), then the
native plugins in `app/src/main/java/com/nephrospectra/plugins/` are compiled in
and registered from `MainActivity`.

To build locally:

```bash
npm ci
npm run build
npm install --no-save @capacitor/cli@6 @capacitor/core@6 @capacitor/android@6
npx cap add android      # first run only
npx cap sync android
cd android && ./gradlew assembleRelease
```

Required locally: JDK 17 and Android SDK 34.

Native plugins:

| Plugin | File | Purpose |
| --- | --- | --- |
| `NephroAcousticFlow` | `plugins/NephroAcousticFlowPlugin.java` | True 48 kHz `AudioRecord` PCM-float capture, 8-frame noise-floor calibration, streamed 2048-sample frames |
| `NephroDipstickCamera` | `plugins/NephroDipstickCameraPlugin.java` | CameraX YUV_420_888 pad grid sampling with per-pad RGB mean, channel variance and luminance CV for the intact-RBC speckle test |
