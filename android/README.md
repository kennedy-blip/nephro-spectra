# Android host project

This is a **real Capacitor 6 Android project**, committed to the repository so
that the release workflow can build it without regenerating it. It is kept in
sync with `capacitor.config.json` by `npx cap sync android`.

## Local build

```bash
npm install
npm run build
npx cap sync android          # copies dist/ into app/src/main/assets/public
cd android && ./gradlew assembleRelease
# → app/build/outputs/apk/release/nephro-spectra-v28.0.0.apk
```

Requires JDK 17 and Android SDK 34 (`android-actions/setup-android` provides
both in CI).

## What is hand-written vs generated

| Path | Origin |
| --- | --- |
| `app/src/main/java/com/nephrospectra/plugins/*.java` | **Hand-written** — the two native clinical plugins |
| `app/src/main/java/com/nephrospectra/clinical/MainActivity.java` | **Hand-written** — registers both plugins before the bridge starts |
| `app/src/main/res/xml/network_security_config.xml` | **Hand-written** — TLS-only, required because the vault syncs to Supabase |
| `variables.gradle` | Hand-edited — SDK 24/34, CameraX 1.3.4 |
| `app/build.gradle` | Generated, then patched by `scripts/bootstrap-android.py` (CameraX deps, signing config, deterministic APK name, versionCode 28) |
| `gradle/`, `gradlew`, `res/mipmap-*` | Generated by Capacitor |
| `app/src/main/assets/public/` | Generated by `cap sync` — **not tracked** |

`scripts/bootstrap-android.py` is idempotent and re-applies the hand edits after
a `cap add`/`cap sync`. It fails loudly if a plugin's declared package stops
matching its directory, because Gradle compiles by path.

## Native plugins

| Plugin | File | Purpose |
| --- | --- | --- |
| `NephroAcousticFlow` | `plugins/NephroAcousticFlowPlugin.java` | True 48 kHz `AudioRecord` PCM-float capture, 8-frame noise-floor calibration, streamed 2048-sample frames |
| `NephroDipstickCamera` | `plugins/NephroDipstickCameraPlugin.java` | CameraX `YUV_420_888` pad grid sampling with per-pad RGB mean, channel variance and luminance CV for the intact-RBC speckle test |

Both are bound to the web layer through `src/native/nativeBridge.js`, which
detects `window.Capacitor`, calls the plugin, and falls back to Web Audio /
`getUserMedia` when the page is running in a plain browser. The polyglot runtime
inspector reports which path is live.

## Permissions

`RECORD_AUDIO`, `CAMERA` and `MODIFY_AUDIO_SETTINGS` are declared in
`AndroidManifest.xml`. Both plugins request their permission at runtime through
`@PermissionCallback` and reject the call with a clear message if it is denied.

## Signing

CI signs with `ANDROID_KEYSTORE_BASE64` when that secret is present, and falls
back to an ephemeral self-signed key so a fork can still produce an installable
APK. The release build is verified with `apksigner verify` and checked to
contain `assets/public/index.html` — a build that silently ships an empty WebView
fails the workflow.
